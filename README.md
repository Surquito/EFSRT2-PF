# Sistema de Evaluación de Desempeño de Empleados

Esta será una aplicación de escritorio desarrollada en **Python** diseñada para automatizar, gestionar y analizar las evaluaciones de desempeño del personal dentro de una organización. El sistema permite registrar métricas de rendimiento, gestionar objetivos por empleado y centralizar la información para la toma de decisiones en el área de Recursos Humanos.
